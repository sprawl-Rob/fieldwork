Connect your Microsoft 365 account

In Microsoft Entra → App registrations, create Fieldwork Local for accounts in your organization only. Under Authentication, add a Mobile and desktop applications platform with this custom redirect URI:

http://localhost:8765/api/mailbox/callback

Under API permissions, add Microsoft Graph Delegated permissions Mail.Read and User.Read. Do not create a client secret. Copy the two IDs from Overview below. Microsoft will ask you to consent when you sign in.

Sign-in tokens stay in memory and are cleared when you disconnect or quit Fieldwork. Candidate message text and review history are stored locally on this Mac.
